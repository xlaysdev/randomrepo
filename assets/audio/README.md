# Background music

The web game supports optional looping background music. Add your own licensed tracks to this folder using these exact names:

- `day.ogg` — school / hallway scenes
- `club.ogg` — Literature Club scenes
- `sunset.ogg` — calm / emotional scenes
- `tense.ogg` — glitch / suspense scenes

MP3 files with the same names are accepted as a fallback (`day.mp3`, etc.). OGG is preferred for compact web delivery. If a track is missing, the game simply stays silent for that scene.

Check each track's license and required attribution before publishing. The official DDLC soundtrack is available in the [DDLC Fan Pack on Steam](https://store.steampowered.com/app/717250/), but owning the soundtrack does not automatically grant permission to redistribute its files inside a public website.

The in-game Settings panel includes a background-music toggle and volume slider.
